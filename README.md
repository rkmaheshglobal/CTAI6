# CTAI6 — CBSE Class 6 Computational Thinking & AI

Interactive learning companion for the **CBSE Computational Thinking and Artificial Intelligence** Student Handbook (Class 6).

## Repository structure

| Path | Description |
|------|-------------|
| `CTAI/` | Official handbook PDF and extracted text |
| `web/` | Next.js student & teacher app |

## Quick start

```bash
cd web
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000)

## Features

- Student dashboard with XP, streaks, and chapter progress
- Teacher dashboard with class codes, roster, and answer keys
- All CT & AI handbook exercises with step-by-step solutions
- Per-question diagram crops from the official PDF

See [web/README.md](web/README.md) for full documentation.
